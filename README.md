# 🎓 آية باك 2027

موقع تعليمي خاص بشهادة البكالوريا في الجزائر 🇩🇿 — مبني بلغة **HTML + JavaScript + CSS** بالكامل، بدون أي خادم (يعمل على أي استضافة مجانية).

---

## 🔑 الدخول

- الصفحة الأولى هي **صفحة كلمة السر** (الحقل مخفي بنقاط).
- كلمة السر هي: **`aya 2026`**
- لتغييرها: افتح الملف `js/app.js` وعدّل السطر الأول:
  ```js
  const APP_PASSWORD = 'aya 2026'; // ← كلمة السر
  ```

## 🗺️ هيكل الموقع

```
index.html    → صفحة الدخول (كلمة السر)
home.html     → الصفحة الرئيسية: قائمة المواد (مع بحث)
subject.html  → وحدات المادة
unit.html     → دروس الوحدة
lesson.html   → الدرس: مشغل فيديو + ملفات PDF + صور + أزرار تمارين
admin.html    → ⚙️ لوحة التحكم (إضافة وتعديل كل شيء)
```

### 🎬 صفحة الدرس
- **مشغل فيديو مخصص** يدعم:
  - روابط مباشرة بالصيغ **MP4 / WebM / OGG / MOV** (الموصى بها: MP4).
  - روابط **يوتيوب** (تُشغَّل تلقائياً بالمشغل المدمج).
  - **الملفات المرفوعة من الجهاز**.
  - تحكم كامل: تشغيل/إيقاف، تقديم/إرجاع 10 ثوان، شريط تقدم، صوت، **سرعة العرض (حتى 2x)**، ملء الشاشة، نافذة عائمة، تنزيل.
  - اختصارات لوحة المفاتيح: `مسافة` تشغيل، `→ ←` تقديم، `↑ ↓` صوت، `F` ملء الشاشة، `M` كتم.
- **ملفات PDF**: عرض وتنزيل.
- **صور**: معرض + عارض مكبّر (أسهم التنقل + Esc للإغلاق).
- **أزرار تمارين**: كل زر يفتح تمريناً (PDF / فيديو يُشغَّل في المشغل / رابط).

## ⚙️ لوحة التحكم (admin.html)

منها تُدار **كل** محتويات الموقع:

| التبويب | ماذا تفعل فيه |
|---|---|
| 📚 المواد | إضافة/تعديل/حذف/ترتيب المواد مع أيقونة ولون |
| 📑 الوحدات | إضافة وحدات لكل مادة |
| 🎬 الدروس | إضافة دروس لكل وحدة |
| ➕ المحتوى | إضافة **الفيديوهات وملفات PDF والصور والتمارين** لكل درس — برابط أو برفع ملف من الجهاز |
| 💡 نسخ احتياطي | تصدير/استيراد كل البيانات بصيغة JSON + إعادة تعيين |

> 💡 كل تعديل يُحفَظ فوراً في متصفح الزائر (localStorage) والملفات المرفوعة تُخزَّن في IndexedDB — لا تحتاج لأي قاعدة بيانات خارجية.

> ⚠️ لأن التخزين داخل المتصفح، فالمحتوى الذي تضيفه يظهر على **جهازك** فقط. إن أردت نشر المحتوى للجميع: عدّل المحتوى الافتراضي في ملف `js/data.js` (أو انشر الموقع مع بياناتك المصدَّرة)، أو اربطه لاحقاً بخدمة مثل Firebase.

## 🚀 كيف تشغّل الموقع؟

**محلياً**: افتح `index.html` مباشرة في المتصفح، أو:
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

**على الإنترنت (مجاناً)**:
1. ارفع الملفات إلى مستودع GitHub.
2. من إعدادات المستودع فعّل **GitHub Pages**.
3. أو اسحب المجلد وأفلته في [Netlify Drop](https://app.netlify.com/drop) — يعمل مباشرة.
