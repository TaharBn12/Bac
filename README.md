# 🎓 آية باك 2027

موقع تعليمي خاص بشهادة البكالوريا في الجزائر 🇩🇿 — مبني بلغة **HTML + JavaScript + CSS** بالكامل، مع **قاعدة بيانات سحابية (Supabase)** يراها جميع الزوار.

---

## ☁️ الربط بـ Supabase (خطوة واحدة — الأهم!)

الموقع مربوط بمشروعك في Supabase، لكن **جداول قاعدة البيانات يجب إنشاؤها مرة واحدة فقط**:

1. افتح مشروعك في: **[supabase.com/dashboard](https://supabase.com/dashboard)**
2. من القائمة الجانبية اختر: **SQL Editor**
3. افتح ملف `supabase-setup.sql` (الموجود مع ملفات الموقع)، انسخ **كل محتواه** والصقه في المحرر
4. اضغط **Run** — سترى رسالة نجاح ✅

**كيف أتأكد أن الربط نجح؟**
افتح `admin.html` وادخل — سترى شارة خضراء **«☁️ متصل بالسحابة»** أعلى اللوحة. بعدها:
- كل ما تضيفه من دروس وفيديوهات وملفات **يظهر لجميع الزوار على كل الأجهزة** 🎉
- عند أول دخول للوحة التحكم يُزرع المحتوى الافتراضي تلقائياً في السحابة
- الملفات التي ترفعها من جهازك تُخزَّن في **Supabase Storage** وتكون متاحة للجميع

**ملاحظات:**
- إن تعذّر الاتصال بالسحابة (لا إنترنت مثلاً) يعمل الموقع تلقائياً بالوضع المحلي ويُزامن عند عودة الاتصال.
- الحد الأقصى لحجم الملف المرفوع في الخطة المجانية ~50MB — للفيديوهات الكبيرة استعمل روابط يوتيوب (تُشغَّل داخل الموقع مباشرة).
- إعدادات الاتصال موجودة في `js/supabase-config.js`.
- ⚠️ **إن كنت نفّذت النسخة القديمة من ملف SQL** (بمفتاح `aya 2026`) **نفّذ النسخة الحالية مرة أخرى** لتحديث مفتاح الكتابة إلى كلمة مرور الأدمن الجديدة `taha 2026` — التنفيذ مكرر وآمن.

## 🔑 كلمات المرور

| المكان | كلمة المرور |
|---|---|
| 🔓 دخول الموقع (الصفحة الأولى) | **`aya 2026`** |
| ⚙️ لوحة التحكم (admin.html) | **`taha 2026`** |

- صفحات الموقع **للزوار فقط** — لا توجد فيها أزرار تعديل أو نصوص ظاهرة عن لوحة التحكم.
- **الدخول للوحة التحكم**: افتح `admin.html` مباشرة (أو اضغط **القفل الصغير الخفي** أسفل يسار أي صفحة بعد الدخول) — **لا يشترط تسجيل دخول الموقع**، تظهر بوابة كلمة مرور الإدارة فوراً.
- حتى لو ضغط زائر القفل بالخطأ، تطلب اللوحة كلمة مرور الإدارة ولا يمكنه الدخول بدونها.
- عند فتح صفحة درس/مادة بدون تسجيل دخول، يُحفظ مكانك وتعود إليها تلقائياً بعد إدخال كلمة السر.
- كلمتا المرور تُداران من `js/supabase-config.js` (`SITE_PASSWORD` و `ADMIN_PASSWORD`).
- ⚠️ **تغيير كلمة مرور الأدمن**: عدّل `ADMIN_PASSWORD` في `js/supabase-config.js` **وفي** ملف `supabase-setup.sql` (استبدل `taha 2026`) ثم **أعد تنفيذ ملف SQL** في SQL Editor — لأنها مفتاح الكتابة في السحابة.

## 🎨 الأيقونات (SVG في كامل الموقع)

كل أيقونات الموقع رسومات **SVG** حادة على كل الشاشات (لا إيموجي):
- مكتبة الأيقونات في `js/icons.js` — استعمل `svgIcon('الاسم')` في JS أو `<i data-icon="الاسم"></i>` في HTML.
- أيقونة كل مادة تُحدَّد بثلاث طرق (من لوحة التحكم):
  1. **اسم أيقونة SVG**: مثل `math`, `atom`, `dna`, `book-open`, `bulb`, `fr`, `gb`, `globe`, `mosque` — [عرض كل الأسماء في js/icons.js]
  2. **رابط صورة** (https://...) — مع معاينة مباشرة أثناء الكتابة.
  3. إيموجي قديم محفوظ في البيانات — يُحوَّل تلقائياً إلى أيقونة SVG مكافئة عند العرض.
- لتغيير أيقونة مادة موجودة: اضغط زر الصورة بجانبها في تبويب المواد.
- الصور المرفوعة إلى مخزن Supabase تعمل أيضاً كأيقونات (روابط `sb:`).

## 🗺️ هيكل الموقع

```
index.html    → صفحة الدخول (كلمة السر)
home.html     → الصفحة الرئيسية: قائمة المواد (مع بحث)
subject.html  → وحدات المادة
unit.html     → دروس الوحدة
lesson.html   → الدرس: مشغل فيديو + ملفات PDF + صور + أزرار تمارين
admin.html    → ⚙️ لوحة التحكم (إضافة وتعديل كل شيء)
```

### 🎬 صفحة الدرس
- **مشغل فيديو مخصص** يدعم:
  - روابط مباشرة بالصيغ **MP4 / WebM / OGG / MOV** (الموصى بها: MP4).
  - روابط **يوتيوب** (تُشغَّل تلقائياً بالمشغل المدمج).
  - **الملفات المرفوعة من الجهاز**.
  - تحكم كامل: تشغيل/إيقاف، تقديم/إرجاع 10 ثوان، شريط تقدم، صوت، **سرعة العرض (حتى 2x)**، ملء الشاشة، نافذة عائمة، تنزيل.
  - اختصارات لوحة المفاتيح: `مسافة` تشغيل، `→ ←` تقديم، `↑ ↓` صوت، `F` ملء الشاشة، `M` كتم.
- **ملفات PDF**: بطاقة باسم الملخص الذي تضعه أنت فقط، مع أيقونتي **المشاهدة** و**التنزيل** — لا يظهر الرابط للطالب.
- **صور**: معرض + عارض مكبّر (أسهم التنقل + Esc للإغلاق).
- **أزرار تمارين**: بطاقات واضحة تتكيف تلقائياً: شبكة متوازنة على الكمبيوتر واللوحي، وزر كامل العرض وسهل اللمس على الهاتف. كل بطاقة تفتح تمريناً (PDF / فيديو يُشغَّل في المشغل / رابط).

## ⚙️ لوحة التحكم (admin.html)

منها تُدار **كل** محتويات الموقع:

| التبويب | ماذا تفعل فيه |
|---|---|
| المواد | إضافة/حذف/ترتيب — **تعديل شامل** (الاسم والأيقونة واللون والموضع) من نافذة واحدة، ونسخ المادة كاملة |
| منظّم المحتوى | شجرة مادة ← وحدة ← درس مع بحث، وإضافة وحدة/درس من مكانه، وبناء مسار كامل (مادة + وحدة + درس) بنقرة |
| الوحدات | إضافة/حذف/ترتيب — تعديل العنوان و**نقل الوحدة لأي مادة** وتحديد موضعها و**نسخها بكل دروسها ومحتواها** |
| الدروس | إضافة/حذف/ترتيب — تعديل العنوان و**نقل الدرس لأي وحدة** وتحديد موضعه ونسخه مع محتواه |
| المحتوى | إضافة الفيديوهات وPDF والصور والتمارين — **تعديل العنوان والرابط والنوع والموضع**، معاينة المورد، ونسخه إلى أي درس |
| نسخ احتياطي | تصدير/استيراد JSON + إعادة تعيين + حالة السحابة |

كل التعديلات تتم عبر **نافذة تعديل أنيقة** (بدل النوافذ المنبثقة البدائية) مع معاينة مباشرة للأيقونة — و15 لوناً للمواد.

> 💡 مع اكتمال ربط Supabase يُحفظ كل تعديل **في السحابة فوراً** ويظهر لجميع الزوار. بدون سحابة يُحفظ في متصفح الجهاز الحالي فقط (localStorage + IndexedDB).

## 🚀 كيف تشغّل الموقع؟

**محلياً**: افتح `index.html` مباشرة في المتصفح، أو:
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

**على الإنترنت (مجاناً)**:
1. ارفع الملفات إلى مستودع GitHub.
2. من إعدادات المستودع فعّل **GitHub Pages**.
3. أو اسحب المجلد وأفلته في [Netlify Drop](https://app.netlify.com/drop) — يعمل مباشرة.
